# 🚀 NewsTrace v2.1.0 Release Notes (350 Major Commits)

We are excited to announce **NewsTrace v2.1.0**, featuring 350 high-impact additions across autonomous scraping, deterministic NLP, UI/UX aesthetics, DevOps pipelines, and unit test suites!

---

## 🌟 Major Highlights & New Features

### 1. 🧠 Comprehensive Deterministic NLP Suite
- **Emotion Analyzer**: 6-factor emotional classification (Joy, Anger, Fear, Sadness, Surprise, Neutral).
- **Credibility Scorer**: Multi-factor journalistic credibility and source integrity rating.
- **Entity Stance Detector**: Contextual positive/negative stance extraction towards named persons/orgs.
- **Political Leaning & Polarization**: Rhetoric marker classification across Left, Center, and Right.
- **Headline Sensationalism & Clickbait**: Mathematical index quantifying hyperbole and punctuation charge.
- **Advanced Readability**: Flesch-Kincaid ease, Gunning Fog index, and syllable complexity.

### 2. 🕸️ Graph & Network Intelligence
- Bipartite journalist-topic force-directed graph with Vis.js and D3.
- Modularity community detection (Louvain algorithm).
- Co-authorship and shared byline collaboration networks.

### 3. 🎨 Sleek UI / UX Overhaul
- Deep Space futuristic dark theme with glassmorphism panels.
- Live intelligence breaking news ticker.
- Executive audio briefing player (Web Speech Synthesis).
- Dynamic bias radar polar charts and reading mode toggle.

### 4. 🐳 Production CI/CD & DevOps
- 10 GitHub Actions workflows for matrix testing (Python 3.10, 3.11, 3.12), CodeQL, and Docker.
- Multi-container `docker-compose.prod.yml` with Nginx reverse proxy and healthchecks.
- SQLite WAL mode optimization and FTS5 search queries.
- Multi-format exporters for CSV, JSON, HTML, GEXF, and Markdown.
