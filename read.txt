# 🚀 NewsTrace - Autonomous Media Intelligence System

> AI-powered journalist profiling system with **zero LLMs** | Built for competitive edge

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Flask-3.0-green.svg)](https://flask.palletsprojects.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 📋 Overview

**NewsTrace** is an autonomous media intelligence system that profiles journalists across news outlets using multi-agent AI architecture. Built for hackathons with **NO LLMs** - uses classical NLP and graph analysis.

### ✨ Key Features

- 🔍 **Autonomous Website Detection** - Finds official websites from outlet names
- 🕷️ **Smart Web Scraping** - Playwright + BeautifulSoup hybrid scraper
- 🤖 **Multi-Agent System** - Coordinated AI agents without LLMs
- 📊 **Network Graph Analysis** - NetworkX-powered relationship visualization
- 🧠 **Classical NLP** - spaCy + NLTK for entity extraction
- 📈 **Influence Scoring** - PageRank-style journalist ranking
- 🔗 **Cross-Outlet Tracking** - Fuzzy matching across media outlets

## 🛠️ Tech Stack

### Backend
- **Framework:** Flask 3.0
- **Database:** SQLite + NetworkX
- **Scraping:** Playwright, Selenium, BeautifulSoup
- **NLP:** spaCy, NLTK, scikit-learn
- **Search:** DuckDuckGo Search API

### Frontend
- **UI:** HTML/CSS/JS with Bootstrap 5
- **Visualization:** Vis.js, Chart.js, Plotly
- **Design:** Gradient-based modern UI
